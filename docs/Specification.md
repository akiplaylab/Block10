# 仕様書

## 出題

- 全体の数を 2〜20 とし、既知の部分と答えはどちらも 1 以上です。足し算は「既知の部分 + ? = 全体」、引き算は「全体 − ? = 既知の部分」の形で出題します。
- タイトル画面には、10 の固定枠、お気に入りの固定枠 2 つ、ランダム枠があります。お気に入りの初期値は 5 と 20 で、10 ともう片方のお気に入りは選べません。
- ランダムの候補には 2〜20 から異なる数を 1〜3 個選べます。初期値は 5 と 10 です。候補をすべて外して編集画面を閉じた場合は初期値に戻ります。問題ごとに候補を等確率で選ぶため、同じ全体の数が続くことがあります。
- 全体の数ごとに、既知の部分の候補をシャッフルして一巡するまで重複なく出題します。候補が複数ある場合は、巡の境目でも直前と同じ問題を避けます。
- 演算はタイトル画面の設定で選び、プレイ中は固定します。初期値は足し算です。

## 回答と演出

- 「ブロックつき」と「数字をえらぶ」は、正解と最大 2 個の異なる誤答候補を並べ替えて表示します。正解より小さい候補と大きい候補が両方ある場合は、それぞれから 1 個ずつ選びます。「ブロックつき」が初期設定です。
- 「ブロックつき」では盤面を表示し、選んだ数のブロックを足し算では盤面へ、引き算では盤面から移動させます。正解するとブロックがまとまり、虹を表示します。「数字をえらぶ」と「数字を入力する」では盤面を表示せず、正解時に式を光らせます。
- 数字入力では画面のテンキー、またはテンキーにフォーカスした状態で数字キーを使います。入力が正解の途中まで一致していれば次の桁を待ち、正解と一致した時点で確定します。一致しなくなった場合は誤答として入力を消します。C または Delete でも入力を消せます。
- 誤答時は答えより多いか少ないかを表示し、選んだ回答欄を揺らします。その後、同じ問題に再挑戦できます。効果音は初期状態でオンです。
- 正解するたびに虹カウンターが 1 増えます。ブロックや数字を選ぶ方式では「つぎへ」で次の問題に進み、数字入力では自動で進みます。

## 設定と学習履歴の保存

- 演算、回答方法、音、お気に入り、ランダムの候補をブラウザーの `localStorage` に保存します。設定を初期状態に戻しても学習履歴は残ります。
- 正解して問題をクリアした時点で、既知の部分、選択肢、回答の試行と正誤、試行回数、所要時間、完了日時を記録します。履歴は演算別に保存し、固定出題は全体の数ごと、ランダム出題は全体の数も記録してまとめて保存します。既存の足し算の履歴も同じ保存先に引き継ぎます。
- 保存先は本番と各 PR のテスト環境で分かれます。

## オフラインと更新

- 公開ビルドでは Service Worker が公開パスごとにオフライン用のファイルをキャッシュします。本番と PR のテスト環境では、オフライン利用の準備がそれぞれ必要です。
- 起動時、オンライン復帰時、画面が再表示されたときなどに更新を確認します。新しい版は、表示中の画面がタイトル画面になった時点で適用します。プレイ中は「ホーム」に戻るまで切り替えを待ちます。
- PR のテスト URL ではオンライン時に公開内容を優先し、ネットワークへのアクセスに失敗すると保存済みの内容を使います。オフラインのテスト版には「オフライン保存版」と表示します。
