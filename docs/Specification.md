# 仕様書

本書は、Block10 が満たすべき仕様と制約を定義します。

実装方法が変わっても維持すべき内容や、変更に明示的な意思決定が必要な内容を記載します。具体的なアルゴリズム、UI・演出の詳細、調整可能な初期値などは原則として記載せず、ソースコードやテストコードで管理します。利用方法は [利用ガイド](UserGuide.md)、仕様の判断基準となる教育理念は [教育理念](Philosophy.md) を参照してください。

## 出題

- 全体の数は 2 ～ 20 とし、既知の部分と答えはどちらも 1 以上とします。
- 足し算は「既知の部分 + ? = 全体」、引き算は「全体 − ? = 既知の部分」の形で出題します。どちらも式の 2 番目の数を答えます。
- 10 を使った出題を基本とします。
- 固定出題とランダム出題に対応します。ランダム出題では設定された全体の数を等確率で選びます。
- プレイ中は演算を固定します。

## 回答とフィードバック

- 複数の回答方法を提供します。
- 正解・不正解をその場で伝えます。
- 誤答しても同じ問題に再挑戦できます。
- ブロックによって数の全体と部分の関係を視覚的に表現します。

## 学習履歴と設定

- 学習履歴と設定を利用者のブラウザー内に保存します。
- 設定を初期化しても学習履歴は維持します。
- アプリの更新によって既存の学習履歴を失わないようにします。
- 本番環境と各 PR のテスト環境の保存データを分離します。

## 表示言語

- 英語（en）と日本語（ja）に対応します。標準言語は英語とし、翻訳がない文言も英語を表示します。
- 保存済みの言語を優先します。保存値がない場合はブラウザーの優先言語（`navigator.language`）を参照し、日本語（ja、ja-JP など）なら日本語、それ以外や取得できない場合は英語を表示します。地域や IP アドレスによる判定は行いません。
- 設定で English と 日本語 を切り替えられます。選択はその場で反映し、`localStorage` に保存して次回も使用します。ゲーム設定の初期化後も選んだ言語を維持します。
- 表示言語と HTML の `lang` 属性を同期します。翻訳リソースはゲームロジックから分離し、オフラインで両言語を利用できるようにします。
- リポジトリのドキュメントは日本語のみで管理します。

## アプリ名と OGP 画像

- 正式なアプリ名はすべての言語で Block10 とします。アプリ内タイトル、ブラウザーのタイトル、OGP タイトル、PWA Manifest の名称と短縮名、iOS のホーム画面追加用の名称、README のタイトルに使用します。
- SNS メタデータと README は、共通の OGP 画像（`public/ogp.png`）を参照します。画像内には Block10、Play、数式を表示します。

## オフラインと更新

- 初回の準備完了後はオフラインでも利用できます。
- アプリの更新によってプレイを中断しないようにします。
